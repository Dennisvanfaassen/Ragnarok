Healing & Supplies

Choose what the character consumes while hunting and how much RO Control should keep stocked.
Native mode uses inventory items directly; no physical hotkey input is required.

Healing food / item

Humanized healing picks one trigger between 30–60% HP for each healing event, then uses 1–3 items. Multi-item bursts wait 0.2 seconds between uses.

ASPD potion

Automatic reactivation watches the actual ASPD potion status effect. While the effect is active, another potion is never used. It is reactivated after the effect ends. The duration timer is only a fallback if this client does not expose status telemetry.

Hunting setup

Choose a map, then RO Control loads the monsters known for that map. Reference data is merged with monsters actually observed by your SoulBound client.
Private servers can customize spawns and drops. Reference entries are treated as suggestions; live SoulBound observations are marked separately.

Hunt profiles

Save the complete setup for each hunt. A profile remembers the map, monsters, priorities, loot rules, attack skills, healing, supplies, behavior and the saved route for that map.
Example: Byalan Obeaune Farm today, then one click to load your Thara Frog Card Hunt later.

1. Hunting map

2. Monsters & loot

Enable the monsters you want to attack. Each monster can loot everything, loot only selected drops, loot everything except selected drops, or ignore all drops.
Choose a hunting map first.

3. Attack skills

Add targeted combat skills to use as an opener before normal attacks. Example: Bash when SP is at least 50%.

4. Hunting behavior

Healing, emergency items and ASPD consumables are configured under Healing & Supplies.
Priority is strict: lower numbers always win target selection. Example: priority 1 is chosen before 2, and 2 before 3. Distance only breaks ties between monsters with the same priority. A monster set to "Only if it attacks me" joins that same priority order only while it is aggressive. Once combat starts, the target stays locked until it dies.

5. Avoid areas

Add rectangles the bot must not enter while hunting. Targets inside these zones are ignored and routes crossing them are rejected.

Manual Town

Storage, selling and buying are intentionally manual. RO Control handles travel, hunting and looting only.
Automatic town inventory actions are disabled to avoid SoulBound storage disconnects.

1. Town cycle trigger

Equipped items are always protected. Core consumables remain in inventory unless you explicitly add an override rule below.

2. Inventory rules

Your current live inventory is listed here. Choose Keep, Store or Sell for any item. Rules are saved by item ID/name and apply on future town trips too.

Set a target inventory amount. RO Control buys only the missing amount from the Tool Dealer. Item ID is recommended for custom/private-server items.
