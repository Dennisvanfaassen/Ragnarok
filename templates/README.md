# Monster templates

Put one or more cropped PNG images of monsters in this folder.

For best results:

1. Run Ragnarok at the same zoom level you normally use.
2. Take a screenshot with the monster visible.
3. Crop tightly around the monster sprite only.
4. Save it as a PNG, for example:
   - `poring.png`
   - `wolf.png`
   - `target_monster.png`
5. Keep several views/animation frames when one image is not detected reliably.

The bot loads every `*.png` file in this directory and chooses the nearest matching monster.

Do not include the mouse cursor, damage numbers, names, or large pieces of the background in the crop.
